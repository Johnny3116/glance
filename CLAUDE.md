# CLAUDE.md

## Project goals

- This fork is for learning Glance and adapting it into a Nexus-style dashboard.
- Prefer minimal, reversible changes.
- Favor documentation and configuration changes before code changes.

## Editing rules

- Do not make broad refactors unless explicitly asked.
- Do not remove existing functionality.
- Show a plan before implementing multi-file changes.
- Prefer branch-safe, PR-friendly edits.

## Focus areas

- config loading
- widget/page definitions
- dashboard customization
- docs for local development
